## Featured project

**[Smart Bus Tracking and Arrival Prediction System](https://github.com/nadunkanishka/Smart-bus-tracking-system)**
Live bus tracking for Sri Lanka's public bus network, using the driver's phone as the tracker. Passengers see buses on a map with arrival times at each stop, and an admin manages routes, buses and drivers.
React · React Native (Expo) · Node.js · Express · MongoDB · Socket.IO
